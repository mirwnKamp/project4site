Beta setup

The beta server is open. Help us test the new Project4 before the grand opening: install the game in a few steps.

Download L2Project4.exe

Windows 10 / 11 · the launcher downloads and installs the whole game

  1. Download the launcher

    Press the button above to download L2Project4.exe (a few MB).

  2. Open it

    Windows may show "Windows protected your PC", because our launcher is new and not signed yet. Press More info and then Run anyway.

  3. Choose where to install

    Press Yes to install in C:\Games\L2Project4, or No to choose another folder (not Program Files). You need about 37 GB of free space.

    Shortcuts are added to your desktop and Start menu.

  4. Wait for the download

    About 18 GB; the launcher shows the speed and the time left. You can close it at any time: open it again from the desktop shortcut and it goes on from where it stopped.

  5. Press PLAY

    Log in with a new username and password of your choice: the account is created the first time you log in. Write them down, you will need the same ones next time.

    From now on always open the game with the launcher: it installs every update for you.

Already have the game client?

Put L2Project4.exe in your Lineage II folder (the one with the system folder inside) and open it. It only downloads what is different.

Sorry for the restarts

This is a beta: we are fixing and adding things all the time, so the server can restart suddenly, and sometimes many times in the same day. We apologise for the trouble and thank you for your patience and for helping us test.
